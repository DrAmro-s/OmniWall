# OmniWall Pro — Master Edition

A high-performance, GPU-accelerated desktop media wall and reactive live wallpaper dashboard running in Electron / Chromium.

## Core Features
- **Multi-Tile Canvas:** Draggable, resizable video loops, image slideshows, and live web stream tiles.
- **Dual-Buffer Gapless Engine:** Seamless zero-black-frame looping between video playlist items.
- **Universal Audio Player:** Built-in Web Audio API gain stage (up to 200% volume boost), synchronized video peek, and slide-out playlist drawer.
- **Hardware Canvas Wings:** Dynamic outer-edge video reflection via canvas to eliminate widescreen letterbox bars.
- **Apple VisionOS Frosted Glass UI:** Polished glassmorphism interface with auto-hiding presentation controls.
